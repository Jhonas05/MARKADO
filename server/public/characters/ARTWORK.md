# MARKADO character artwork

`byte-v2.png`, `mochi-v2.png`, and `pixel-v2.png` are original project assets generated for MARKADO on 2026-10-26 using OpenAI image generation. They use transparent backgrounds and contain no third-party logos or character references.

The previous SVG assets remain available for history and rollback. The v2 PNG filenames are intentionally versioned rather than overwriting those originals.

## Generation mode

Each asset was generated in `stylized-concept` mode. Byte was generated from text only. Mochi used Byte solely as a set-style reference, and Pixel used Byte and Mochi solely as set-style references.

## Exact prompts

### Byte

```text

Asset type: original collectible character cutout for the MARKADO student character shop
Primary request: Create Byte, a cute friendly compact study robot mascot. Byte has a softly rounded square head, a small bookmark-shaped antenna tab, expressive oval eyes, tiny rounded arms and boots, and a simple checkmark-shaped light on the chest. Make the silhouette immediately recognizable and appealing as a premium collectible.
Scene/backdrop: genuinely transparent background with no floor, platform, frame, border, shadow box, or scenery
Style/medium: polished soft-geometric 2.5D illustration; clean modern shapes, subtle clay-like volume, restrained highlights, crisp edges; friendly academic product aesthetic rather than toy photography
Composition/framing: full body, centered, slight three-quarter front pose, gentle wave, generous transparent padding, readable at 96–256 px
Lighting/mood: soft neutral studio light, cheerful and calm
Color palette: warm ivory shell, charcoal face panel and details, restrained mint/cyan accent lights; high contrast in both light and dark UI
Materials/textures: matte soft-touch shell, faint satin highlights, no noisy texture
Constraints: original project-owned design; transparent alpha; no text, no letters, no numbers, no logos, no watermark; no square background; no drop shadow extending far beyond the character; exactly one character
Avoid: emoji look, clipart, chibi anime conventions, photorealism, aggressive weapons, horror, busy details, thin fragile lines
```
