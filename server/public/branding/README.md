# MARKADO official brand assets

The product-owner-supplied `Markado Geometric Wordmark Logo.png` is the
canonical visual source. `markado-logo.png` is an exact byte-for-byte copy of
that file (SHA-256
`9393B782D4D2C0CA3AB2FFB5F7BB6B067C1BA2279BB449A828304C48B0C6CA54`).

Generated variants use deterministic crop, background transparency, and
high-quality raster resizing only. The letter shapes, spacing, gray details,
and O/checkmark artwork are not redrawn or recolored.

| Asset | Purpose |
|---|---|
| `markado-logo.png` | Untouched 1672 x 941 canonical source |
| `markado-logo-transparent.png` | Cropped 1561 x 272 application wordmark |
| `markado-symbol.png` | Faithful 320 x 320 O/checkmark extraction |
| `favicon-32x32.png` | Browser PNG icon on a deliberate light-neutral surface |
| `apple-touch-icon.png` | 180 x 180 touch icon on the same neutral surface |
| `favicon.ico` | 16, 32, and 48 pixel PNG-backed favicon frames |

No vector or WebP asset is claimed because a faithful source vector and a
verified lossless WebP encoder were not supplied.
